# 🍽️ Hotel Menu Ordering System (Python)

## 📌 Overview

This project is a simple console-based application built in Python that simulates a basic hotel menu ordering system.
It allows users to select items from a predefined menu and calculates the total bill based on their choices.

---

## 🎯 Features

* Displays menu with item names and prices
* Accepts user input for ordering
* Supports ordering up to two items
* Calculates total bill dynamically
* Simple and easy-to-understand program flow

---

## 🛠️ Tech Stack

* Python 3
* Core concepts: dictionaries, conditional statements, user input

---

## ▶️ How to Run

1. Clone the repository:

2. Navigate to the project folder:
   cd hotel-menu-python

3. Run the program:
   python hotelmenu.py
